# ORBIT — 相談相手と作業助手

macOS 13 の Chrome 向けに作ったローカル Web アプリの最初の版です。
Python 3.9 以降の標準ライブラリのみで起動します。

```bash
cd /path/to/orbit-agent
python3 server.py
```

その Mac の Chrome で `http://127.0.0.1:8790` を開きます。
HTML のダブルクリックだけでは動きません。終了はターミナルで Ctrl+C。
他の端末・インターネットへ公開する設計ではありません。

## 無料のローカル AI 接続（既定）

既定では localhost:8080 の llama.cpp サーバーに接続します。モデルサーバーの
導入と起動は次のスクリプトで試せます。Mac 実機での検証はまだ必要です。

```bash
python3 setup_local_ai.py
```

このターミナルを開いたまま、別のターミナルで `python3 server.py` を起動します。
既に ORBIT を起動している場合は、そのターミナルを残してください。
ただし、既存の ORBIT を更新した場合は Ctrl+C で停止して再起動し、
ローカル AI 用の応答待ち時間の延長を反映してください。

スクリプトは固定版 llama.cpp b5808 を macOS 13 向け CPU モードでビルドし、
公式 Qwen/Qwen2.5-7B-Instruct-GGUF の Q4_K_M モデルをダウンロードします。
初回は数 GB のダウンロードとコンパイルが必要です。
モデルの SHA-256 を HTTPS の配布情報から取得し、全ファイルの一致を確認します。
複数ファイルに分割されている場合は全分割を検証します。CMake がなければ
公式 CMake 3.31.8 の macOS universal 版を固定チェックサムで検証して使います。
モデルと実行環境は `~/Library/Application Support/ORBIT/runtime` に保存します。
OS のアップデート、管理者権限、Homebrew の導入は要求しません。
端末の署名警告を解除したり TLS 検証を無効にしたりする操作は行いません。
検証したファイルは再実行時に再利用します。

サーバーのヘルス確認は `/health`、会話は `/v1/chat/completions` を使います。
`ORBIT_LOCAL_PORT` でローカルポートを変更できます。
ローカル AI に API 利用料はありませんが、モデルの性能と応答速度は
Mac の性能と選択するモデルに左右されます。高度なクラウド AI と同等の
品質を保証するものではありません。音声入力の Chrome 提供サービスは別です。

## 有料 API 接続（任意）

`ORBIT_PROVIDER=openai` を設定すると OpenAI API に切り替わります。

OpenAI API のキーを `ORBIT_API_KEY` に設定して起動します。キーをチャット、
ソース、Git、コマンド引数やブラウザの保存領域へ貼らないでください。
macOS の Bash では入力を隠す次の方法が使えます。

```bash
read -s -p 'OpenAI API key: ' ORBIT_API_KEY
printf '\n'
export ORBIT_API_KEY
export ORBIT_PROVIDER=openai
python3 server.py
```

既定のモデルは `gpt-4.1-mini`。`ORBIT_MODEL` で変更できます。
AI サーバーや API キーなしでも記憶・タスクの管理ができます。AI の返答は代用品を生成せず、
未接続と表示します。実 API 接続は別途検証が必要です。
ChatGPT の有料プランとは別に API 利用料金が発生します。

## できることと「進化」

- AI との相談・下書き・計画づくり（API 設定が必要）。
- 会話履歴、ユーザーが保存した記憶、タスク、回答への評価の永続保存。
- 保存した記憶とタスク、直近の評価を次の AI リクエストに含める。
- Chrome の音声認識による入力とブラウザの音声読み上げ。

「目標に沿って動く」では、AI が1〜6ステップの計画を作り、アプリ内の記憶参照・
四則演算・Markdown 下書き保存・タスク登録を実行します。道具の種類と引数を
事前に検証します。一般のシェルや Python コードを AI に実行させません。
実行結果と失敗した箇所は履歴に残り、途中で失敗した場合も完了済みの操作は戻りません。

実行後、AI が結果を振り返って次回用の手順を提案します。名前・説明・確認基準を
検証し、候補として版管理します。「この版を採用」で、次回の計画と通常チャットに
反映します。以前の版を選び直すか「標準手順に戻す」で取り消せます。
これはテキストによる作業手順の更新であり、AI モデルの訓練やアプリのコード変更ではありません。
形式の検証が通っても、作業品質が改善した証拠にはなりません。
確認基準に沿った実際の成果比較は、モデル接続後に行う必要があります。

下書きは `data/drafts/`、履歴・手順は SQLite に保存します。
サーバーを再起動したとき、処理中だった作業は「中断」になります。自動再実行はしません。

AI モデルの自動訓練、コードの自己更新、検索、メール送信、予約、外部ファイル操作は
未実装です。登録したタスクを外部で実行したとは表示しません。
記憶は自動抽出せず、ユーザーが保存・削除します。

## データ

データは `data/orbit.sqlite3` に保存します。`ORBIT_DATA_DIR` で場所を変更できます。
このフォルダをバックアップすれば会話・記憶・タスク・評価を保存できます。
SQLite 自体は暗号化していません。端末のユーザー権限を持つ人はアクセスできます。
OpenAI API 選択時、会話・保存した記憶・タスク・直近の評価を OpenAI に送信します。
Chrome の音声認識では音声がブラウザの提供サービスへ送信される場合があります。
録音ファイルはアプリで保存しません。API キーは環境変数から読むだけで、DB に保存しません。

## 検証

`python3 -m unittest discover -s tests -v`。
HTTP とブラウザ操作、再起動後の永続化はクラウド内で検証します。
Mac 実機の Chrome、実マイク、実際の AI サービスは別途検証が必要です。

現在、18件のテストが通過しています。ブラウザでも、目標入力から実際のローカル操作、
改善候補の採用、次回への反映、標準手順への復帰を確認しました。
AI の計画・振り返りには検証用の固定応答を使いました。実モデルの品質は未検証です。
クラウドから Hugging Face のモデル配布先への通信は CONNECT 403 で遮断されました。
Mac へのファイル転送と無料モデルの導入は未完了です。

Intel macOS compatibility: the installer disables native CPU detection and AVX-512,
uses AVX2, and targets macOS 13.3+. This addresses a reported Apple clang 14
backend crash in x86/repack.cpp; the Mac rebuild remains to be confirmed.
